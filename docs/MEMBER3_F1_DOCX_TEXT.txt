Timestamp Normalization
: Raw timestamps (timestamp, datetime, or observed_at) are coerced via pd.to_datetime(..., utc=True). Rows failing timestamp parsing are dropped immediately. Timestamps are floored to 1-hour UTC boundaries (hourly_bin = observed_at.dt.floor("h")).
Missing Station Coordinates
: Many raw telemetry streams omit geographic coordinates and report only station_id. The pipeline joins records against data/geo/monitoring_stations.geojson. If a station's latitude/longitude is missing from the stream, it is backfilled using the official reference point. Records with unresolvable coordinates are dropped.

8. H3 Spatial Indexing Status in F1
F1 establishes the H3 spatial standard without encroaching on F2 feature extraction:
Canonical Resolution
: 
Resolution 8
 (~0.737 km² cell area, average hexagon edge length ~461.4 meters).
Representation
: 15-character lowercase hexadecimal string (e.g., "886196944dfffff").
Implementation Location
: Implemented in ai-service/preprocessing/spatial_alignment.py:
Python
def bind_h3_cell(lat: float, lon: float, resolution: int = 8) -> Optional[str]:
    if pd.isna(lat) or pd.isna(lon) or not (-90.0 <= lat <= 90.0 and -180.0 <= lon <= 180.0):
        return None
    # Supports both H3 v3 and H3 v4 API bindings
    if hasattr(h3, "geo_to_h3"):
        return h3.geo_to_h3(lat, lon, resolution)
    elif hasattr(h3, "latlng_to_cell"):
        return h3.latlng_to_cell(lat, lon, resolution)
    return None
Deferred to F2
: H3 
k
-ring spatial neighbors, inverse-distance spatial lags, and spatial joins across fire detections and satellite raster grids were intentionally excluded from F1 and deferred to F2.

10. Temporal Leakage Prevention Architecture
Preventing temporal lookahead leakage is mandatory for environmental forecasting models to remain scientifically valid:
Station-Isolated Target Generation
:
Future targets are constructed using backward shifting grouped strictly by station_id:
Python
out_df["target_pm25_t_plus_1"] = out_df.groupby("station_id")["pm25_clean"].shift(-1)
out_df["target_pm25_t_plus_3"] = out_df.groupby("station_id")["pm25_clean"].shift(-3)
out_df["target_pm25_t_plus_6"] = out_df.groupby("station_id")["pm25_clean"].shift(-6)
Leakage Guard
: Target variables are shifted backward so that row 
T
 contains 
y
T+k
. Future target columns are isolated and barred from entering the input feature matrix 
X
T
.
Weather Synchronization
: Weather observations at time 
T
 are merged strictly with air quality observations at time 
T
. Future meteorological forecasts are never backfilled into past ground truth.
No Rolling Leakage Across Partitions
: Rolling statistical aggregations (e.g., 24-hour historical moving averages) compute rolling windows using closed right boundaries (closed='left' or strictly backward-looking intervals), ensuring that observation 
T
 does not incorporate information from 
T+1
.

16. Engineering Decisions & Architectural Tradeoffs
Decision 1: Hourly Floor Aggregation vs. Exact Minute Joining
Context
: Air quality stations report at irregular intervals (e.g., 10:14, 10:28), whereas weather feeds update hourly (10:00).
Alternatives Considered
: Continuous nearest-neighbor KDTree time-matching vs. linear interpolation.
Selection
: Deterministic flooring to the top of the hour (hourly_bin = observed_at.dt.floor("h")).
Justification
: Eliminates non-deterministic join artifacts and matches CPCB's official 1-hour national reporting interval.
Downstream Impact
: F2 satellite overpasses and fire detections align to this same hourly bin.
Decision 2: Coercion of Negative Values to 
NaN
 vs. Zero Clipping
Context
: Optical beta-attenuation gauges and electrochemical sensors can exhibit negative baseline drift under high humidity.
Alternatives Considered
: Clip negatives to 
0.0 μ
g/m
3
.
Selection
: Coerce negative values strictly to np.nan.
Justification
: Atmospheric pollutant concentrations cannot be negative. Clipping to zero biases statistical variance, distorts distribution tails, and masks sensor degradation.
Downstream Impact
: F3 tree algorithms handle missing values directly without skewing loss functions.
Decision 3: Parquet Format for Interim & Processed Storage
Context
: Choosing an on-disk format for cleaned and aligned datasets.
Alternatives Considered
: CSV or SQLite.
Selection
: Apache Parquet with Snappy compression via pyarrow.
Justification
: Parquet preserves exact schema types (avoiding repeated string-to-datetime parsing) and provides columnar performance for downstream feature sets.
